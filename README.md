# Olivara Stays — villa rental site demo

A single-page demo template for a curated holiday-villa rental site: villas, small stays, venues, journal, membership, about and help pages, with an animated hero and generated illustrations.

Demo made by Ashikur Rahman Shaon.

**Everything here is sample content.** "Olivara" is a sample brand; the listings, prices and contact details are invented, and the forms do not send anything.

## Run it

Open `index.html` in a browser. There is no build step and no dependencies (fonts load from Google Fonts).

## Deploy

Import this repository at vercel.com/new and deploy with the default settings, or run `vercel` in this folder with the Vercel CLI.
